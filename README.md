# Analog Clock

A live analog clock rendered entirely with CSS and JavaScript. The hour, minute, and second hands rotate in real time using CSS `transform: rotate()`, updated every second via `setInterval`.

## Features

- Hour, minute, and second hands driven by the system clock
- Smooth real-time updates every second
- Clean minimal face with numeric labels at 12, 3, 6, and 9
- Zero dependencies — pure HTML, CSS, and JavaScript

## Tech Stack

| Layer     | Technology               |
|-----------|--------------------------|
| Structure | HTML5                    |
| Styling   | CSS3 (transforms, positioning) |
| Logic     | Vanilla JavaScript (ES6) |

## Project Structure

```
clock/
├── index.html   # Clock face markup
├── script.js    # Time calculation and hand rotation
└── style.css    # Clock face, hands, and layout
```

## Getting Started

No install needed. Open `index.html` in any browser.
